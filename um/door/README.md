# Porte — Universal Metaphor

Lien public partageable : `https://ericgrimard-pixel.github.io/um/door/`

Cette page est la vitrine 15c : elle présente les deux environnements (côté administration, en démonstration, et côté client) et un environnement DÉMO clairement étiqueté (Inviter, Reçus, Accepter). Une image Open Graph (`og-preview.png`) sert de vignette lors du partage.

Aucun fichier existant du Hub (`um/index.html` et le reste de `um/` hors de ce dossier) n’est modifié pour y pointer. Aucun CNAME n’est ajouté. Le protocole Manifestation n’est pas réajusté (rév. 23.16, `zoneOf`, seuils 20 / 40 / 60 / 80).

Cette surface n’expose ni registre d’invités, ni jetons, ni URL secrète d’administration, ni reçus, ni grand livre, ni adresse de courriel. Le bureau d’invitation réel n’est pas publié ici.

Les schémas, la carte des six zones, le moteur gelé et les sommes SHA-256 restent à côté, dans [`/plumb-dump-data/`](https://ericgrimard-pixel.github.io/plumb-dump-data/).
