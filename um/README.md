# Universal Metaphor — HUB galaxies v20.10 (version sûre)

Prototype privé de démonstration. **Non affilié à la Ligue nationale de hockey.**

Cette copie publique remplace les 32 logos officiels des clubs par des badges neutres
portant uniquement le sigle de l'équipe (`logos/MTL.svg`, `logos/TOR.svg`, …).
Les fichiers gardent les mêmes noms pour qu'un remplacement ultérieur des visuels
ne change pas les adresses.

- Hub : `index.html` (route `#/`)
- Galaxie planétaire : `#/galaxy/planet`
- Galaxies Sports (silos isolés) : `#/galaxy/sports`
- LNH : `nhl.html` → `index.html#/sports/nhl`

Silos d'analyse : finance (`um.analysis.finance.*`) et chaque sport (`um.analysis.sports.<sport>.*`) restent strictement séparés.
